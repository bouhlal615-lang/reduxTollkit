# Soukly — Boutique e-commerce

Application React construite avec Vite, Redux Toolkit, React Router et Bootstrap.

## Démarrer

```sh
npm install
npm run dev
```

## Fonctionnalités

- Catalogue de produits avec recherche par intitulé et filtre par catégorie.
- Ajout, modification et suppression de produits.
- Panier avec gestion des quantités et calcul du total en MAD.

Le catalogue et le panier sont gérés par les slices Redux dans `src/features`.
